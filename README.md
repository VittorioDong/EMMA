# EMMA

EMMA (Embodied Manipulation Media Adaptation) is a framework that enhances Vision-Language-Action (VLA) robot manipulation models (DreamTransfer) by combining a multi-view world model with an adaptive training strategy.

**🌐 [Project Page](https://emma-gigaai.github.io/)** | **📄 [Paper](https://arxiv.org/pdf/2509.22407)** | **⚖️ [License](LICENSE)**

## DreamTransfer

DreamTransfer is a depth-conditioned, multi-view video transfer framework for training and inference on synchronized robot-camera videos. 

### Repository layout

```text
.
├── giga-datasets/   # Dataset readers, transforms, and video utilities
├── giga-models/     # DreamTransfer model and inference pipeline
└── giga-train/      # Training framework and DreamTransfer recipe
```

Main entry points:

- Training: `giga-train/gt_projects/launch.py`
- Trainer: `giga-train/gt_projects/dream_transfer/dream_transfer/dream_transfer_full_trainer.py`
- Inference: `giga-models/scripts/examples/diffusion/dream_transfer/inference_dream_transfer_depth_multiview.py`

### Installation

Use Python 3.10 or 3.11. Install a CUDA-compatible PyTorch and torchvision
build first, then install the local packages:

```bash
python -m pip install -e giga-datasets
python -m pip install -e giga-models
python -m pip install -e giga-train
```

Training with the provided configuration requires DeepSpeed. Inference requires `decord`, FFmpeg support through `imageio-ffmpeg`, and Video-Depth-Anything. 

SageAttention acceleration is optional. Pass `--disable_acceleration` when it is unavailable.

### Training

The default configuration reads machine-specific paths from environment variables:

```bash
export DREAMTRANSFER_TRAIN_DATA=/path/to/training/dataset
export DREAMTRANSFER_PROMPT_CACHE=/path/to/default_prompt_t5.pkl
export DREAMTRANSFER_VAE_MODEL=/path/to/vae
export DREAMTRANSFER_TRANSFORMER_MODEL=/path/to/transformer
export DREAMTRANSFER_CONTROLNET_MODEL=/path/to/controlnet
export DREAMTRANSFER_OUTPUT_DIR=/path/to/output

python giga-train/gt_projects/launch.py \
  --project dream_transfer \
  --config configs.dream_transfer_full_multiview \
  --runner dream_transfer.DreamTransferFullTrainer
```

GPU IDs, precision, checkpoint intervals, and optimization settings are in `giga-train/gt_projects/dream_transfer/configs/dream_transfer_full_multiview.py`. The default recipe uses 121-frame video batches and a 1920 x 480 combined three-camera view.

Each training sample must provide the fields consumed by `DreamTransferTransform`, including the video, its dimensions and length, prompt embeddings, and the depth/control video. Dataset adapters can map a native representation into these fields.
