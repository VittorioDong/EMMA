# DreamTransfer model package

This package provides the DreamTransfer Transformer, ControlNet, tokenizer VAE,
text encoder, scheduler, and inference pipeline.

```bash
python -m pip install -e giga-models
```

See the repository-level `README.md` for complete training and inference
instructions.
